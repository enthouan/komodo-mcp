Contributions go through pull requests against `main` on [GitHub](https://github.com/enthouan/komodo-mcp). Keep each change focused on one issue, and keep secrets and real Core data out of code, tests, logs, and screenshots; the test suite uses synthetic fixtures and credentials only.

## Documentation sources

The README and the files in `docs/` are the canonical documentation. This website renders them at build time, so edit the Markdown in the repository rather than the website. A guide that moves or a README section that is renamed fails the website build until the website metadata is updated.

## Website

The website lives in `website/` and uses Astro Starlight with pnpm. Install the Node version in `.nvmrc`,
then run these commands from the repository root.

```sh
npm install --global pnpm@10.34.1
pnpm install --frozen-lockfile
pnpm --dir website exec playwright install chromium webkit
pnpm website:dev
pnpm website:check
```

`website:check` verifies the social image, runs Astro diagnostics, builds the production artifact once, then runs output contracts and Playwright browser checks against it. See `website/README.md` for each stage.

<Aside type="note" title="Maintenance and releases">
