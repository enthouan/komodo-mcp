## Logging

`RUST_LOG` filters diagnostics on stderr; the default level is `info`. For example, `RUST_LOG=komodo_mcp=debug,rmcp=warn`. Credential values are redacted at every level.

## Fixed limits

- Connection timeout: 5 seconds. Each complete Core operation: 15 seconds, including reading the response body.
- List pages: `page` defaults to 0, `page_size` defaults to 30 and accepts 1–100.
- Automatic redirects are disabled and TLS certificate verification stays enabled.
