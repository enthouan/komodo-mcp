komodo-mcp is a single Rust executable. Your MCP client can launch it over stdio or connect to a persistent HTTP service. Each instance calls your Komodo Core API with one API key and secret.

## Choose an installation path

Use native stdio when your MCP client launches a process. Choose Docker Compose for a persistent endpoint that authenticates each MCP request with a bearer token.

## Connect and read your stacks

Choose a [Core identity](/getting-started/komodo-credentials/) with Read access to the Stacks you want to inspect. Set its address, API key, and secret in the server environment. For HTTP, configure a separate inbound bearer token and put it in your MCP client. The [installation guide](/docs/self-hosted-beta/) has commands for each path.

After initialization, run `tools/list`. Call `list_stacks` with `{}`. To investigate a Stack, copy its returned ID into `get_stack` and `stack_diagnose`. The [three-tool triage walkthrough](/docs/operator-quickstart/#discover-and-diagnose-with-three-tools) includes the expected discovery results and the arguments for each read.

To verify the three-tool restriction in a client that supports direct calls, request the read-only `list_deployments` tool with `{}`. This instance should reject the call as an unknown tool.

Set `KOMODO_ENABLED_TOOLS=list_stacks,get_stack,stack_diagnose` before starting either transport to use the three-tool triage configuration. To keep your usual tool set except image history, leave `KOMODO_ENABLED_TOOLS` unset, set `KOMODO_DISABLED_TOOLS=get_image_history` in the server environment, and restart. [Configuration reference](/reference/configuration/#select-individual-tools)

## Release and source

The beta downloads include checksums and <a href={INSTALLATION_SOURCE_URL}>matching Corresponding Source</a>. To build the current published <a href={RELEASE_URL}>{RELEASE_TAG} release</a> from its Git tag, use the pinned Rust toolchain. See the [native stdio source-build guide](/getting-started/stdio/).

git checkout ${RELEASE_TAG}
cargo build --locked --release --bin komodo-mcp`} />
