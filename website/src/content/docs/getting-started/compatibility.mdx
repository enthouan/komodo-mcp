## MCP protocol

The repository's compiled-stdio tests initialize the actual release executable with protocol **{MCP_PROTOCOL_VERSION}** using the official rmcp **{RMCP_VERSION}** SDK, discover the read-only tools, call inventory tools, and verify shutdown on stdin EOF. Only the stdio transport exists today.

## Komodo Core

komodo-mcp pins `komodo_client` **{KOMODO_CLIENT_VERSION}** and its HTTP fixtures represent Komodo Core {KOMODO_CLIENT_VERSION}. Opt-in disposable Core/Periphery smoke runners are documented in the [operation walkthrough](/docs/operations-walkthrough/) and other walkthroughs; they run only when explicitly enabled and are not part of CI.

## Platforms

- **Linux:** CI builds and tests with Rust {RUST_TOOLCHAIN} on GitHub's Ubuntu runners for every pull request and push to `main`.
- **macOS:** on 2026-11-16 the locked release build and the fresh-checkout `stacks_on_server` demonstration completed on macOS (x86_64) during this website's verification. macOS is not covered by CI.
- **Windows and other targets:** not verified. Prebuilt binaries and a documented target matrix are tracked in [#42](https://github.com/enthouan/komodo-mcp/issues/42).
