## MCP protocol

The repository's compiled-stdio tests initialize the actual executable with protocol **{MCP_PROTOCOL_VERSION}** using the official rmcp **{RMCP_VERSION}** SDK, discover the read-only tools, call inventory tools, and verify shutdown on stdin EOF. HTTP tests exercise authenticated discovery and inventory against a controlled Core fixture.

## Platforms

The [native distribution workflow](https://github.com/enthouan/komodo-mcp/blob/main/.github/workflows/native-distribution.yml) builds the locked Rust {RUST_TOOLCHAIN} application from its source archive on each target, then exercises the extracted executable against a synthetic Core fixture.

| Target | Native test host | Runtime requirement |
| --- | --- | --- |
| Linux x86-64 | Ubuntu 24.04, x86-64 | 64-bit Linux with the static musl executable |
| Linux arm64 | Ubuntu 24.04, arm64 | 64-bit Linux with the static musl executable |
| macOS Intel | macOS 15, Intel | macOS 15 or later |
| macOS Apple silicon | macOS 15, Apple silicon | macOS 15 or later |

The [container distribution workflow](https://github.com/enthouan/komodo-mcp/blob/main/.github/workflows/container-distribution.yml) exercises the same multi-platform OCI archive on native Ubuntu 24.04 runners for `linux/amd64` and `linux/arm64`, using authenticated HTTP discovery and an inventory read through Compose. See [native binaries and matching source](/docs/distribution/) and [Docker Compose installation](/docs/container/) for setup and verification. Windows and other targets have no recorded build or runtime coverage.

See the [native downloads and supported platforms](/docs/self-hosted-beta/#native-stdio).
