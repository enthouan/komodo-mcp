## Start by listing your stacks

Connect over [native stdio](/getting-started/#native-stdio) or [Docker Compose with authenticated HTTP](/getting-started/#docker-compose). Both start read-only.

```text title="Ask your MCP client"
List the stacks I can access in Komodo and show their current status.
Use list_stacks and do not change anything.
```

To investigate a failed Stack, use its returned ID with `stack_diagnose`. The [diagnosis walkthrough](/docs/operator-quickstart/) shows how to follow the cited evidence.

<CardGrid>
  <GuideLinkCard icon="puzzle" title="Tool catalog" href="/reference/tools/" action={`Browse all ${Object.keys(catalog.tools).length} tools`}>
    Use `fleet_health` to find a workload that needs attention. For a failed Stack, `stack_diagnose` brings together its history, alerts and recent logs. Each catalog entry lists inputs, results, required grants and whether the tool makes changes.
  </GuideLinkCard>

  <GuideLinkCard icon="approve-check-circle" title="Stable support policy" href="/docs/stable-support/" action="Check your setup">
    Live tests on Linux x86-64 cover native stdio and authenticated HTTP with Core and Periphery 2.3.2. Look up your platform and MCP client to see whether the evidence comes from a live connection, a test fixture or a configuration review.
  </GuideLinkCard>

  <GuideLinkCard icon="code-branch" title="Upgrade and rollback" href="/docs/upgrade-v1/" action="Follow the upgrade guide">
    Keep your working native executable or record the current Compose image digest before you upgrade. After restarting, check that your client discovers the same tools and can read a familiar Stack. Repeat those checks if you restore the previous version.
  </GuideLinkCard>

  <GuideLinkCard icon="magnifier" title="Troubleshooting" href="/guides/troubleshooting/" action="Find your symptom">
    A `401` from `/mcp` points to the bearer token your HTTP client sends. If `list_stacks` succeeds but returns an empty list, check the Core account’s Read permission on a Stack you expect to see.
  </GuideLinkCard>
</CardGrid>
