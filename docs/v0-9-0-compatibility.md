Core/Periphery combinations outside the pinned pair, desktop clients over HTTP, Windows packages, and platforms outside the native/OCI target lists are untested for the candidate. Performance evidence is specific to the measured workload, process and host.

## Evidence needed from the two candidate runs

For each #48 transport, retain the native executable or platform digest, observed Core and Periphery versions, the client's initialize identity/version and protocol, actual platform and completed stages. Exercise scoped and denied identities, read/operate filtering, stopped containers and list-only inspection denial, preview/apply including stale sync, interrupted execution recovery with independent single-submission evidence, secret checks and final resource lists. Record separate fixture, rebuilt-source and live results. [Disposable runner](../tests/fixtures/disposable-core/README.md)

For #49 use one packaged native binary and compare the same seeded inventory and incident evidence over stdio. Record page size, concurrency, repetitions, host load, process identities, calls, bytes and unsupported combinations. Keep direct fixture HTTP and real-Core timings distinct. There is no HTTP MCP comparator claim in the stdio harness. [Benchmark workloads](../benchmarks/README.md)
