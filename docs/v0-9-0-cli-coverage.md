# Official km CLI coverage for v0.9.0

The [v1 contract](https://github.com/enthouan/komodo-mcp/blob/e8432d39d6c12c5278d26f17959f041884ab5a4c/docs/contracts/v1.json) and [MCP tool catalog](https://github.com/enthouan/komodo-mcp/blob/e8432d39d6c12c5278d26f17959f041884ab5a4c/docs/tool-catalog.json) are pinned to the reviewed baseline at `e8432d39d6c12c5278d26f17959f041884ab5a4c`.

Komodo CLI v2.3.2 at [`cc1c5aa5dabb738e843c47f5e87fc040648c2bb7`](https://github.com/moghtech/komodo/tree/cc1c5aa5dabb738e843c47f5e87fc040648c2bb7) supplies the command definitions. Each command below uses the `km` prefix. For nested commands, a short alias replaces the final subcommand. In the Executions table, prepend `km execute` to every entry. Full means the native sequence carries out the stated command scope. Partial identifies usable subsets. Deferred identifies an unimplemented workflow. Intentionally excluded identifies a CLI-local or deliberately unsupported capability. A terminal shell works outside this mapping.

The CLI selects an instance using `--profile`, repeatable `--config-path` and `--config-keyword`. The `--debug-startup` flag (`--debug`) controls configuration diagnostics. Each MCP process uses one configured Core identity. Tool availability also follows the process allow/deny selection. Read requires the Core permissions for the selected object. Operate, configuration-edit, prune and terminal refer to `KOMODO_ALLOW_OPERATE`, `KOMODO_ALLOW_CONFIGURATION_EDIT`, `KOMODO_ALLOW_PRUNE` and `KOMODO_ALLOW_TERMINAL`. [source](https://github.com/moghtech/komodo/blob/cc1c5aa5dabb738e843c47f5e87fc040648c2bb7/client/core/rs/src/entities/config/cli/args/mod.rs)

These mappings compare the pinned CLI implementation with each MCP workflow. Using packages built from `e8432d39`, the live Core tests exercised the MCP equivalents of container listing and inspection, Stack inventory and a single saved Deployment submission. ResourceSync coverage includes stale review and denied refresh. The benchmark measured a complete Stack inventory and used a synthetic fixture for incident triage.
