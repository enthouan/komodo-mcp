# Komodo API family coverage for v0.9.0

The [v1 contract](https://github.com/enthouan/komodo-mcp/blob/e8432d39d6c12c5278d26f17959f041884ab5a4c/docs/contracts/v1.json) and [MCP tool catalog](https://github.com/enthouan/komodo-mcp/blob/e8432d39d6c12c5278d26f17959f041884ab5a4c/docs/tool-catalog.json) are pinned to the reviewed baseline at `e8432d39d6c12c5278d26f17959f041884ab5a4c`.

The upstream revision is Komodo Core/Periphery v2.3.2 at [cc1c5aa5dabb738e843c47f5e87fc040648c2bb7](https://github.com/moghtech/komodo/tree/cc1c5aa5dabb738e843c47f5e87fc040648c2bb7). Supported indicates an available workflow for the named family. Partial narrows the available operations, input scope or returned fields. Deferred indicates an uncovered family. Excluded identifies a deliberate boundary. Check [compatibility](v0-9-0-compatibility.md) for the versions and clients exercised against real services.

The packaged candidate exercised container inventory and inspection, a Stack configuration change, rejected ResourceSync applies and Deployment update recovery on both Linux transports. The Intel macOS benchmark verified seven live Stacks with a read-only account. Remaining rows describe the mapped API and its documented tests. Each linked live result covers the operation and grants that its scenario used. [Linux regression](releases/v0.9.0/disposable-regression.md) · [Benchmark samples](releases/v0.9.0/benchmark-samples.json)
