# Reporting a vulnerability

Sign in to GitHub and use [Report a vulnerability](https://github.com/enthouan/komodo-mcp/security/advisories/new) to contact the maintainers privately. The form becomes available when the repository is public and private vulnerability reporting is enabled.

Include the affected release or commit, what you observed, and the conditions needed to reproduce it with synthetic data. Omit credentials, private Core addresses, and identifying logs. Keep the report and any follow-up in the private advisory.

For ordinary bugs and support requests, follow the [guide to filing a sanitized issue](https://komodo-mcp.com/reference/reporting-issues/).
